# Bhagavad Gita Break Timer

A mindful desktop break and habit-tracking Chrome extension built with Manifest V3 and Vanilla JavaScript.

## Features
- **Mindful Micro-Breaks:** Schedules automated desk breaks using `chrome.alarms`.
- **Curated Shlokas:** Serves 58 curated Bhagavad Gita verses focused on equanimity, outcome detachment, focus, and posture.
- **Random Deck Engine:** Implements a shuffle queue via `chrome.storage.local` to ensure zero verse repetition until all 58 are experienced.
- **Desk Ergonomics & Hydration:** Built-in glass logging and physical posture prompts.
- **100% Offline & Private:** Zero external servers, zero tracking, and runs completely locally.
